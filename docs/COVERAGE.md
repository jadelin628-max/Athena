# 考纲覆盖矩阵（COVERAGE）

> 目的：为 **Athena 2.2.0 内容全覆盖** 提供「考纲/考点条目 → 现有卡片 → 缺口 → 建议动作」的矩阵，并给出题库全量（数学三 / 微观 / 统计）的题型-考点依据清单。
> 本文件是**只读分析产物**：不改 `data/*.js`、不改卡面、不改题库；所有数字与结论均标注依据来源（仓库文件 + 页码/题号，或 URL）。
> 生成方式：由 `backup/scratch/coverage/` 下的只读脚本从 `data/*.js`、`参考文件/`（含已抽取文本 `参考文件/_extract/`）机械统计得到，可重跑复核（见 §11 附录 A）。

## 0. 阅读方式与本文边界

- **矩阵三张**：§3 统计（北大光华 431 数理统计，按茆诗松教材 8 章）、§4 微观（北大光华 431 微观，按十八讲 + 考点族）、§5 数学三（公共课，按考纲章）。
- **状态口径**（三档，判定规则见 §1.5）：`已覆盖` / `覆盖不足` / `缺失`。
- **建议动作**（四类，取自任务口径）：`改卡`（内容/挂载问题就地修）/ `拆卡`（一卡多知识点）/ `新增卡`（考纲有、卡没有）/ `新增题型`（题库题型体系缺）。
- 本文**不承诺**「卡数 = 掌握度」：卡数只说明内容资产存在性；每条的「覆盖不足」都写出了具体缺口（无例题、例题非目标院校、内容错位、条目缺失之一）。
- 不确定项一律进 §10「待确认」，不在正文里下断言。

### 1.5 统计口径与判定规则（避免误读）

- **「关键词命中」**：在该条目所属 `cat` 内，卡片的 `title` 或 `front` 命中关键词的**卡片数**（不是出现次数）；零命中后另用 `title+front+back` 全文 + 同义词复核（`missing-recheck.md`），防止「用词不同」被误判为缺口。
- **例题数**：`EX` 例题条数；同一真题可挂多张卡，故例题条数 ≥ 被覆盖卡片数。
- **状态判定**：
  - `已覆盖`：考纲条目在对应 `cat` 有卡，且核心子条目有例题或有多张 ★4-5 卡支撑；
  - `覆盖不足`：存在以下任一——(a) 有卡但**无例题**且该章有可用真题；(b) 例题来源**非目标院校**（统计科以光华 431 为目标）；(c) 内容**错位**（卡在别的 `cat`）；(d) 该条目只 1-2 张卡或只 ★3 薄卡；
  - `缺失`：全库（跨科）`title+front+back` 全文 0 命中。
- **`math3` 概率统计**：数三考纲的概率统计**归统计科**（`AGENTS.md:67`），因此 §5 该块按「跨科复用」处理，只标注调度与例题口径，不建「math3 缺概率统计卡」的伪缺口。
- 全部文件名、页号、卡 id 均可回读：卡 id 见 `backup/scratch/coverage/cards-*.md`，题号见 `bank-questions.md`，原文页见 `参考文件/_extract/*.txt`。
