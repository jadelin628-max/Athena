# Athena 2.0.0 发行介绍

**2026-10 · 上一发行标签：v1.14.0**

---

## 开篇

v1.14 的时候，Athena 还是一枚「把卡片记牢」的工具：FSRS、错题本、移动端 Dock。

**2.0 把它升格成综合自我提升平台**——记忆仍是内核，但旁边长出了行动系统：习惯怎么立住、专注怎么编组、计划怎么落地、坚持怎么被看见。

一句话：

> **知识用 FSRS 记住，日子用行动系统过稳。**

---

## 六个大件

### 1. 习惯树（RSIP）

把习惯做成一棵可检查的树，而不是一张打卡清单。

- **今日结算**：全员检完才结算；未检查 = 未完成；零点自动收前一日
- **容忍天数**：漏一天可容；连续失败才移除——对齐 Lally 66 天（18–254），不卖「21 天神话」
- **标签组 minK**：同组有成员撑着，本检不整组塌掉
- **失败级联回库**：内化进度不丢；每日最多 1 个新节点入树
- **强化**：自动（内化 50/100 → +1/+2）或手动（每日 1 次，更严表述）
- SVG 思维导图；过程反馈只有次数 / 点阵——**没有连击惩罚，没有物质兑换**

### 2. 专注链（CTDP）

专注不是「开了个番茄钟」，是可编组、可继位、可复盘的作战编制。

- **任务单元**：计时结束才算完成；记内容 / 达成 / 完成度
- **编制树番号**：`#N` 单元 · `●N` 组 · `▲N` 群 · `◆N` 集团
- **计划模式**：未填满整链清空；高层次创建 / 转正须计划模式
- **判例**：下必为例；侦查可转正（重选类型）
- **主链**：唯一，可继承；主链崩溃 → 最强普通链继位
- **完成度询问** + 日均完成度趋势（柱 = 分钟，点 = 均完成度）

### 3. 计划（WOOP）

以 WOOP 为主干：愿望 → 结果 → 障碍 → 计划。P 步就是「如果-那么」执行意图（软校验外部情境 + 具体动作）；外部提示并入障碍；环境审计帮你移除 / 改造诱因。

### 4. 里程碑

叙事向成就，**没有积分、排行、兑换、连击、失败羞辱**。

- 50 条 Steam 式风味名（定式已成 / 七日之约 / 继位大典 / 肝帝觉醒…）
- 解锁 = 可核对条件 + 时间 +「这说明…」+ 深链去对应模块
- 主页最多露出 1 条，不抢学习 KPI

### 5. 原理知识库

「原理」从长文变成可检索知识库：五分类目录 + 搜索 + 条目详情。

条目带研究者 / 年份 / 出处，证据分级 🟢 / 🟡 / ⚠️ 照录，不编造研究。CTDP / RSIP 明确标为社区方法论。覆盖多巴胺 RPE、习惯回路、SDT 与过度辩护（**因此不做物质奖励**）、情绪重评、Posner 注意、间隔与提取、执行意图与 WOOP，以及学习风格 / 21 天 / 自我损耗等证伪清单。

### 6. 界面与工程

- 亮色默认，蓝 `#3B82F6` / 粉 `#D4537E` 双色
- 桌面侧栏 · iOS 底栏 + 安全区
- Today 双栏；⌘K 命令面板跳转
- 行动数据与学习库**分键存储**，互不污染
- 设置 · 行动可调数值 / 名称 / 风味，支持重置与云同步
- 构建：`app.js` 由 `src/` 零依赖拼接；CI 锁行尾 LF，保证 app.js / src 同步

## 升级须知

- **数据**：学习库键不变，2.0 读旧进度；行动数据落在独立键（`athena_act_v1` 等），不碰 FSRS 库 `updatedAt`
- **整科重构过的科目**（Python / C / C++ / Java / JS / Rust / 日韩法西等）学习进度按该科公告重置
- **无物质奖励 / 无连击惩罚**是产品红线，不是还没做
- 算法：FSRS-6 对齐官方 ts-fsrs / fsrs-rs v6.x（21 权重）；掌握度为标注 ⚠️ 的自创对数压缩
