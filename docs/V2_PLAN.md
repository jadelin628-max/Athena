## 2. 行动系统

### 2.1 习惯树（RSIP · 产品名不变）
**模型（实现名可 `policy`，UI 文案「习惯」）**
```text
HabitNode {
  id, title, detail?,
  parentId, groupId?,
  difficulty, level(强化 +n),
  internalize 0..100,     // 内化进度，失败不丢
  onTree, lastOk, failCount, createdAt
}
HabitGroup { id, name, color, minK }   // 容错名额，可编辑
```

**规则**
1. 入树：当日成功后可加入；**每日最多 1** 个新节点上树。
2. 失败：**级联熄灭子孙**；节点回「习惯库」；**内化进度保留**。
3. 组：同组点亮数 ≥ `minK` ⇒ 本次失败不因组内保护被移除（可配置）；`minK` 可编辑。
4. 强化：时间阈值类可 `+1/+2`，失败可降级不连坐（可配）。
5. 根元习惯：「每日打开习惯树并添加 1 条」等可选模板。

**UI**：SVG 思维导图（树状/径向）· 拖拽改父 · 缩放折叠 · Inspector 侧栏 · 习惯库列表 + 模板。

### 2.2 专注链（CTDP）
- 神圣座位：触发说明 + 「就座」开始；成功 `#N` 工作量证明。
- **下必为例**：可疑行为 → 「清链重来」|「永久允许此例外」（判例表）。
- 预约链：预约信号 → 15 分钟内启动；可选二次预约。
- 侦查任务：5 分钟低门槛，可延长。
- 精锐/普通链 + **继位**（精锐崩溃由最强普通链继承）。
- 层级 `# → ## → ###` 二期可扩，2.0 至少单层链 + 记录。

### 2.3 计划工具
- **WOOP 主干**（W 愿望 → O 结果 → O 内心障碍 → P 如果-那么）；旧独立「如果-那么 / 环境审计」并入 WOOP（P 步 / 障碍步外部提示），加载与同步丢弃 `ifThen`/`envAudit`。
- 产出仅作计划记录（**不升格为习惯**、无「升格为习惯草稿」）；习惯树另行维护。
- 帮助 = 国策/习惯设计手册（零敲牛皮糖、农村包围、组容错、不破不立）。

### 2.4 里程碑
- 路标/判例/内化满；主页最多 1 条；无排行、无赎买；崩溃文案「调试器」。

## 10. H 波修订（推送前 · 版本仍 2.0.0）

> 讨论定稿 · 派单 H1–H5。红线不变：无 miss 状态、无连击惩罚、FSRS 不动。

### 10.1 习惯树 · 今日结算（H1）
- 无 **miss**；未检查 = 违反候选；单习惯仅 **已完成 / 未完成** + 编辑/删除。
- **全部习惯检查完**才可点 **「今日结算」**；二次确认后综合结算（组 minK + 强化）。
- 结算：未完成且未受组保护 → 回库+级联；受保护/完成 → 只调内化与强化。**零点自动结算**前一日。
- 强化：自动按内化阈值（50→+1、100→+2，可设置）；**手动每日仅 1 次、1 个习惯、内化保留 50%**，且须改写要求更严。
- 组容错 UI 仅组列表；树下规则简述 → 帮助。

### 10.2 专注单元（H2）
- **计时结束**才可「完成」；开始时必填任务内容；结束记录 **是否达成原定 + 完成度 0–100%**；链记 `startedAt`。
- 侦查到期 → **转正**（再选类型）或放弃；转正后与一般单元相同。
- 类型默认：**专注 / 突击 / 生活 / 计划 / 侦查**（仅未转正侦查）；名称可编辑。
- 统计：**仅** 专注热力图（实际完成分钟）+ 趋势图。

### 10.3 编制树（H3）
- 层次默认名：**任务单元 → 任务组 → 任务群 → 任务集团**（可编辑）。
- 番号：单元 **`#N`**（全局流水、永不重排）；组 **`●N`**、群 **`▲N`**、集团 **`◆N`**（各层独立递增、不回收）。
- UI：**竖列树**（缩进+折叠+连接线），归属不靠标签；游离 = 根「未编入」可筛选。
- 默认 **自由 N 叉**；创建向导可选 **三三制模板**（建议每组 3 子，不强制）。
- **计划模式**：预建大任务+截止；二次确认（写明整链风险）；未填满 → **整链清空**；临近截止 **弹窗 + 主页/模块角标**。
- 风味：**总开关**（开后显示类型名与层次名）；`#` 始终显示。

### 10.4 设置与同步（H4）
- 设置新栏 **「行动」**：dailyAddLimit、manualLevelPerDay、manualLevelKeepRatio、failInternalizePenalty、自动结算、单元时长/预约窗/侦查时长、结构（自由|三三制）、风味开关、类型名/层次名、planDueRemindDays 等。
- **重置行动模块**（备份后清空 athena_act/groups/focus）。
- 行动数据 **云同步**（id+updatedAt 取新，日志/判例并集）。

### 10.5 导航（H5）
- 删除主页底部快捷入口；**原理** 进侧栏；规则入帮助。

## 12. 里程碑与成就（新模块 · 原理对齐）

> 产品名：**里程碑**（避免「勋章/等级」）。内在反馈，禁止赎买与连击惩罚。

### 12.1 原则
- **过程反馈**：叙事路标、进度具象、回顾陈述；非积分/排行/兑换。
- 解锁文案 = **条件 + 时间 +「这说明…」+ 链到习惯/专注/学习**。
- 主页最多 **1** 条最近里程碑；无失败羞辱。

### 12.2 数据（`athena_mile_v1`，独立学习库）
```text
MilestoneDef { id, title, kind, rule, hint }
MilestoneHit { id, defId, at, note? }
```
- kind: `habit` | `focus` | `learn` | `mixed`
- rule: 纯函数谓词（如 habit 内化满、focus 连续完成、learn 清空到期）

### 12.3 UI
- 一级导航「里程碑」：时间线 + 分类筛选 + 未解锁列表（只显示条件，不剧透阈值可选）
- 今日/主页卡片：最近 1 条 + 「查看全部」
- 解锁时轻提示（可跳过），无强制动画

### 12.4 示例规则（实现首批）
- 习惯：内化 100%、树上连续 7 日结算完成、组 minK 稳定 14 日
- 专注：主链 #10 / #50、精锐继位 1 次、日实际专注 ≥120 分
- 学习：单科首次清空到期、连续 7 日有复习
