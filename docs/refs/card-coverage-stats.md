## 1 口径与边界

### 1.1 什么是「一行」
- 茆诗松 8 章：**节内知识点**为粒度 —— 一个节若含多个小节（如 8.4.1–8.4.5）就拆成多行，行号与页号来自 `docs/refs/stats-textbook.json` 的 `entries[]`；小节标签一律回读，不手写。
- 14 册专题讲义：以「定义组」为粒度（如专题九的「定义1.1 充分统计量 / 定义1.4 因子分解定理」合为一行），页号为该册 PDF 物理页。
- 计量经济学讲义：以节为粒度（§1.1–§4.4，占位节与作业题页不计入）。
- 页码一律 **PDF 物理页码、1 基**；茆诗松的印刷页码 = PDF 页码 − 22（表中 `pagePrinted` 列）。

### 1.2 四类标注 + 两个扩展标记
| 标记 | 含义 |
| --- | --- |
| `有讲义有卡片` | 讲义有该知识点，且现有卡足以承载（卡片 id 见各行） |
| `讲义有而卡片无` | 缺口：讲义有该知识点，199 张卡无一张承载 |
| `双方都有但需重写` | 有卡但内容不足以入库（过薄 / 无公式 / 多知识点挤一张 / 重复卡） |
| `卡片有而讲义无（整合卡/超纲）` | 卡片存在但讲义无对应知识点：跨节方法论整合卡，或超纲补充卡 |
| `有讲义有卡片（覆盖不足）`（扩展） | 有卡但只覆盖讲义该点的部分子项，需要补强而不是从零补写 |
| `crossChapter`（扩展） | 该卡的承载行在别的章，跨章复用同一张卡，不重复计入覆盖数 |

## 7 估量口径（补写卡片数怎么来的）与三科复用建议

### 7.1 本册的估量判据
1. **先看讲义子项数**：一个节里的子项（小节 / 定义组）越多、每子项独占的题型越独立，补写需求越大；子项数直接回读 `docs/refs/stats-textbook.json`，不凭印象。
2. **再看现有卡数**：该行 `cards` 为空 → 纯缺口；卡存在但只覆盖子项的一部分 → 覆盖不足（补强 1–2 张）。
3. **最后看是否可出题**：纯概念铺垫（如「变量间的两类关系」「多项分布（工具分布）」）给 `suggest 0` 并写明理由；能出计算题/选择题的公式点给 1 张；整节 4 个以上子项且各自有独立公式的（如讲义 6.5 贝叶斯、8.2 多重比较、专题九 Basu）给 2 张。
4. 每个缺口/补强都必须写出可回读的依据（节号 + 页号 + 现状卡号），见 §3 与 §5 的「依据」列。

### 7.2 三科（统计 / 微观 / 数学三 / 统计真题）可复用的口径建议
1. **以「节—知识点」为行、不要用整章**：整章作行会让覆盖率虚高，也定位不到缺口页。
2. **行内必须带能回读的锚点**：`material + section + items[] + page`，其中页号从 baseline 的 JSON 派生（本次用 `backup/scratch/refs-cards-stats/skeleton.json` 解析），禁止手写。
3. **四类状态 + 两个扩展标记**（覆盖不足 / crossChapter）要进 schema；`crossChapter` 用于一张卡跨章复用，避免同一卡被重复计入分子。
4. **例题与 EXAMPLE 一律排除**并单独统计；卡片所附 `EXAMPLE` 只作只读附注。
5. **缺口与补强都要给可复算判据**（子项数 / 页数 / 现有卡数 / 是否可出题），不要凭感觉给数字。
6. **校验脚本必须自证**：条目数可复算、缺口数可复算、页号引用可回读、四类计数自洽（见 §8）。
