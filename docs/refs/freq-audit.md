## 一、数据可用性结论（逐文件逐字段）

### 1.1 `docs/refs/math3.json`（741,517 B）—— **逐题标注存在，但 105/297 题为占位符**

- 顶层键：`_meta` / `tool` / `materials` / `rulings` / `coverage` / `years` / `answer_manifest` / `formula_recheck`。
- 路径 `years.<年>.questions[]`，每项字段 `{id, year, no, kind, type_candidate, type_label, knowledge[]}`。
- 题量：**297 题**，年份 2010–2022（2010–2020 各 23 题，2021–2022 各 22 题）。
- **可用逐题知识标签只覆盖 2020–2022 的 67 题**（22/22/23），且这 67 题里 `"题面/知识点待读图确认"` 占位符数为 0。
- **2010–2019 的 105 题 `knowledge[]` 全部是同一占位符字符串 `"题面/知识点待读图确认"`**；同 105 题的 `type_candidate` 为 `unknown`。`coverage.note` 自述：unknown 表示 2010–2019 解析文本层碎裂、无法可靠归类，需读图后确认。
- 剔除占位符后共 **176 个不同标签**，分布极度长尾：≥20 次 1 个、≥10 次 4 个、恰好 1 次 **144 个**。
- 标签粒度不一致，例：「线性代数（行列式/方程组）」(20) 这类粗章级标签，与「sin 的差化积」这类一次性解题子步骤并存。
- **结论：math3 的逐题标注仅 67 题可信；且第一波 29 张新卡中没有任何数学三卡片 → 本文件对本轮判定无直接用途（不构成证据，仅作数据可用性说明）。**

### 1.2 `docs/refs/micro.json`（580,421 B）—— **有「族级」考频，无「知识点级」标注**

顶层 33 键：`schema` `generated_note` `materials` `page_offsets` `stats` `lowyield` `ocr_noise` `j18_chapters` `j18_pages` `rev_years` `ans_years` `pair` `pair_notes` `xlsx` `xlsx_check` `xlsx_modes` `xlsx_unmatched` `family_counts` `family_counts_txt` `families` `cards_total` `cards_by_cat` `cards_by_cat_txt` `cat_family` `gap_notes` `formulas_direct` `formulas_rederive` `figures` `rulings` `batch` `pair_map` `limits` `extra`。

## 四、结论与建议

### 结论

1. **用户投诉部分成立，但不足一半**。29 张里明确偏冷门的是 **7 张**（nx07、jj13、jj15、jj16、jj17、pb15、pb17，其中 jj13/jj15/jj16/jj17/pb17 是三份统计真题语料零命中）＋ 需复查 3 张（jj14/ll12/pb14 命中 4–6）。**另有 4 张是真题高频**（xr04 75、xr05 59、we15/we16/gm21 在占 35.53% 的 C 族），说明这一波并非整体偏冷。
2. **偏冷门的集中区是「计量/回归」cat（jj13–jj17 五张里四张冷门）与「概率论理论底层」（pb15/pb17）**。这两类恰是教材有、真题少的结构性缺口。
3. **统计新卡存在系统性缺陷：16/16 无例题**（微观 13/13 有）。按 `DATA_SCHEMA.md:45-53`「例题仅真实真题；无真题不配例题」，这批卡 0 例题本身就是「无真题可挂」的信号——它既是考频结论的证据，也是质量问题的证据。
4. **微观侧的高频族 C 是当前最薄的**（卡数/题数 1.19），而 A 族 2.14、E 族 4.14 明显过度覆盖 → 2.1.2 后续增量应优先 C 族。
5. **数据基础设施不足**：统计要做出真正的「知识点→真题」考频量表，必须先有逐题标注；`statq.json` 目前连 `sourceText` 都是空的。

### 建议（7 条，按优先级）

1. **【高】给 16 张统计新卡补真题例题，或对补不上的卡明确标注「理论背景卡·真题语料零命中」。** 首选挂：xr04←真题册 line 6031（NP 基本引理 14 分）、xr05←line 5625 等似然比题、pb16←line 1793（Borel-Cantelli 20 分）、pb14←中山大学 432 2016 选择题（line 8789）。**无法挂例题的 5 张（jj13 jj15 jj16 jj17 pb17）应在卡面或元数据标注冷门属性**，避免用户按「高频考点」预期学习。
2. **【高】jj13 / jj15 / jj16 / jj17 / pb17 降星或退出第一波主推。** 依据：三份统计真题语料（真题册+解析册+合集）零命中，且真题册 grep `投影|偏误|遗漏|约束回归|线性约束` 返回 No matches。**但不要删除**——教材（茆诗松/古扎拉蒂/伍德里奇）有该点、其他院校 432 可能考；建议降为 ★2–★3 并把它们从「高频强化」路径移到「背景了解」路径。
