# 数学三真题族转录基线（2010–2022）

> 任务：`t4 [refs-math3]`（Athena 2.2.0 前置）。**本文件与 `docs/refs/math3.json` 是「题库全量」的直接输入**；题面/公式的最终依据一律是裁片 + 自带 `read_image` 亲读，OCR 文本层只用于定位。
> 证据文件：`docs/refs/rulings/math3.md`（七字段裁定，含全部 sha256 与等效命令）；机读索引：`docs/refs/math3.json`；年 checkpoint：`backup/scratch/refs-math3/index-*.json`；校验脚本：`backup/scratch/refs-math3/check-index.mjs`。

## 1. 口径与交付

- **族文件命名**：按任务契约用 `docs/refs/math3.md` / `docs/refs/math3.json` / `docs/refs/rulings/math3.md`（`docs/refs/README.md` §3.5 示例名 `math3-zhenti.*` 为命名示例，以任务契约为准）。
- **材料**：
  - 材料 A（真题册）＝ `参考文件/真题/数学/5、【1987-2025年】考研数学三真题/3、2010-2022考研数学三真题.pdf`，52 页；页↔年：2022 p2–5、2021 p6–9、2020 p10–12、2019 p13–16、2018 p17–20、2017 p21–24、2016 p25–28、2015 p29–32、2014 p33–36、2013 p37–40、2012 p41–44、2011 p45–48、2010 p49–52。
  - 材料 B⟨年⟩（解析册）＝ `参考文件/真题/数学/6、【1987-2025年】考研数学三真题答案及解析/⟨年⟩年数学三真题答案解析.pdf`；2020 册 7 页（页脚印刷页码从「• 5 •」起）、2021 册 9 页（有原生文本层但排版碎裂）、2022 册 26 页（p26 为整页「答案速查」）；2010–2019 册各 7–13 页，**p1（2014–2016 为 p1–p2）是「数学(三)参考答案」清单页**，逐题列出 `(N) X` 形式的答案。
- **工具**：`tools/refs-vision.py`（t1 交付）。命令模板 `参考文件/_venv/Scripts/python.exe tools/refs-vision.py --pdf "<PDF>" --page <1基> --dpi 150 [--box x0,y0,x1,y1] --out "<PNG>"`；`--box` 是 PDF 点（原点左上、y 向下），150 dpi 下 `点 = 像素 × 0.48`；同参数必同 sha256。
- **可入库清单**：见 §5 与 `math3.json` 的 `answer_manifest`（口径同 `tests/fixtures/bank-answer-manifest.json`：`{kind:"choice",a:"C",src}` / `{kind:"fill",anchor,src}`）。
- **纪律**：`data/bank_*.js` 零改动；不跑 `npm run build`；裁片目录 `backup/scratch/refs-math3/img/` 被 `.gitignore` 忽略，凭「命令 + sha256」重建。

## 2. 读图裁定总览

- 裁定文件 `docs/refs/rulings/math3.md`：**编号小节 60 条 + 低产页抽样表 28 条 = 88 条**。
- 覆盖：2022 年 22 题题面 + 解析关键式子（R01–R24）、2021 年 22 题（R01–R14）、2020 年 23 题（R01–R12）、2010–2019 解析册答案清单页 10 条、真题册低产页抽样 28 页（R01–R28）。
- 置信度判据（同 `docs/refs/README.md` §3.3）：high ＝ 逐字清晰且与独立复核一致；medium ＝ 至少一处需判断；low ＝ 只能读大意、不得作入库依据。

题源页 = 真题册 PDF 物理页；解析页 = 该年解析册 PDF 物理页。2010–2019 的题面文字仍以 OCR 定位为主（真题册文本层在这些年是 0 字），**字母答案与填空锚点已按 §4/§5 的口径取证**；这些年份中题源页落在低产页抽样集合内的题目，`math3.json` 的 `stem_evidence` 已给出该页裁片路径 + sha256 + 生成命令。
